### Critical issues for confirmatory interpretation

1. **Name the population and denominator.** For relation `r`, use a common set `V_r` of unique, eligible anchor–edit pairs with two adjudicated binary labels and independently confirmed gold relation `r`. Freeze inclusion and weights before scoring. Compute `UFR = sum(1[pred_anchor != pred_edit] for pair in V_preserve) / len(V_preserve)` and `CCAR = sum(1[pred_anchor == gold_anchor and pred_edit == gold_edit] for pair in V_change) / len(V_change)`. Joint accuracy uses the latter numerator on the declared relation or pooled set. Undefined denominators return NA. A change between harm subtypes can preserve the binary label, so define relations separately for secondary 14-way analysis. Report flow from sampled anchors through attempts, annotation, validation and scoring, with reasons for losses by family, sampling stratum and intended-to-observed relation. A quota or model-error-enriched sample estimates performance under its benchmark composition. A population claim requires a defined sampling frame, known inclusion probabilities and explicit handling of validation attrition.
2. **Replace the H1 rule at the boundary.** A percentile bootstrap on all-zero cluster outcomes necessarily returns `[0, 0]`. It has no way to represent unseen failures. With sparse events the result can depend heavily on one conversation. Report raw counts, event-bearing clusters and leave-one-conversation sensitivity. Before holdout, choose an interpretable practical threshold and a procedure calibrated for the planned design, including sparse outcomes. If precision is inadequate, report the observed rate and its limits descriptively. An exact independent-binomial interval on pooled pairs would treat shared anchors as independent. [Field and Welsh (2007), Sections 3.3 and 4](https://doi.org/10.1111/j.1467-9868.2007.00593.x)
3. **Use a substantive paired comparator.** For a deterministic target-only detector, identical model input implies the same prediction on both arms. It therefore has UFR = 0 on preserving pairs and CCAR = 0 on changing pairs. A fixed majority-class prediction has the same properties. Reversed binary predictions on changing pairs yield raw flip rate 1 and CCAR 0. Treat these as sanity checks and report preserving-pair joint accuracy alongside UFR and CCAR. Select a context-capable comparator for the confirmatory claim, with matched examples and comparable threshold/training regimes. A full-context result above the target-only structural value shows some correct contextual adaptation under the benchmark. A claim of evidence use additionally requires a separate evidence-alignment assessment or a matched control that tests the relevant evidence.

### Required before pilot and protocol freeze

- **G3 validation and power.** Lock the adjudication rules, minimum acceptable validation yield and rationale before observing pilot results. Retain initial blinded votes and report pre-adjudication agreement, category prevalence and disagreement by arm, intended relation and family. Analyze a preregistered stricter-consensus subset as a sensitivity check, keeping the benchmark primary set fixed. Shared raters and shared anchors can induce correlated errors. A proposed planning simulation can vary rater sensitivity/specificity, shared item difficulty, dependence across arms and family-specific validation yield, then apply the actual adjudication rule to inspect relation misclassification. Parameters need defensible ranges or pilot estimates and simulation output cannot stand in for human labels. For the proposed 50 originals and 100 edits, the nominal assignment is 450 first-pass condition ratings at three per condition, plus training, repeats and adjudication. The 150 conditions may contribute far fewer than 50 independent conversations to each eligible relation/family. Use pilot conversation counts, validation yields, cluster-size distribution, paired model discordance and a practical effect threshold to estimate attainable precision under plausible scenarios. The proposed 300 anchors are a planning quantity.
- **G4 clustered inference.** Resample originating conversations with all anchors, edits and predictions bundled. Use the same cluster multiplicities for every model in a contrast. For a pair-weighted metric, recompute total successes over total eligible pairs on every draw, preserving weights and the sampling design when applicable. A mean of per-conversation rates estimates a different quantity. Report eligible pair, anchor and conversation counts, denominator-empty resamples, event concentration and strata with too few independent groups. If templates are reused across conversations, inspect cross-conversation dependence and report a template-family sensitivity analysis. Conversation bootstrap intervals are conditional on adjudicated labels and fitted model checkpoints. For stochastic retraining, prespecify seed aggregation and report seed-to-seed variation separately. Counting each checkpoint seed as another independent conversation understates uncertainty. [Field and Welsh (2007), Sections 3.3–5](https://doi.org/10.1111/j.1467-9868.2007.00593.x)
- **G4 selection and multiplicity.** Freeze model versions, input truncation, thresholds and calibrators using permitted development data. List primary contrasts and the direction/practical difference for each, plus the design-appropriate test used to generate valid p-values. Apply Holm to the fixed family of primary p-values. Label marginal 95% intervals accordingly and keep exploratory model, family and category breakdowns distinct from confirmatory decisions. A pair of independently computed marginal CIs cannot supply a paired difference test. [Holm (1979), Section 1 and Theorem 1](https://www.ime.usp.br/~abe/lista/pdf4R8xPVzCnX.pdf)
- **Missing scores and cost.** Fail validation of the prediction table for missing keys, duplicate keys or invalid probabilities. For genuine timeouts or abstentions, preregister coverage reporting and a failure-sensitive analysis that keeps the benchmark denominator, alongside any common complete-case sensitivity. Define how abstentions enter UFR, where mapping them to an ordinary label can artificially improve stability. Record comparisons on the same items with measured workload units and count retries, failures and policy overhead if routing is later authorized. Costs and seeds never increase the effective statistical sample size.
