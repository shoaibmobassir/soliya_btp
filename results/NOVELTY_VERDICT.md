## Falsifiable minimum contribution

Test whether a companion-harm detector follows specific earlier relational evidence, such as a stated boundary and its later withdrawal or reaffirmation, when classifying a byte-identical reply. Independently and blindly adjudicate every arm from the same prefix-only view, including the original. Compare gold-confirmed relational changes in both label directions with coherent, gold-confirmed distractor edits matched on position, length and lexical salience. Record whether annotators locate the proposed evidence, whether detector decisions adapt correctly, and whether context-only, edit-artifact and recency controls explain the apparent effect. Evaluate on held-out conversations and edit-template families. This is a Stage 0 proposal for protocol revision, with choices and feasibility thresholds to be set through the later gates.

**Stop or pivot** if a checked study or implementation already evaluates that same task with independently validated hold/change arms and a comparable evidence test. Pivot if approved data access is unattainable, or later feasibility work cannot produce coherent validated contrasts that resist artifact controls. A study using newly authored, non-derived dialogues would require a separately scoped review and would support claims about those stimuli. A well-measured null detector effect on valid pairs is an interpretable result.

## Focused follow-up: explicit user boundaries

The [design candidate](../protocols/RELATIONAL_EVIDENCE_DESIGN.md) asks whether the same companion reply crosses an explicit user boundary that is applicable at the time of reply. The key diagnostic changes the status or scope of the relevant instruction and compares that change with a similarly worded edit to an unrelated instruction. Raters would independently judge each prefix and focal reply. The lead repeated the duplicate search on 2026-11-12 using this narrower specification.
